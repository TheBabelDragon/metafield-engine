# C3 field-swarm ingest

`c3-field-swarm` nodes talk ESP-NOW to each other. MetaField sees them over USB serial.

```
C3 fleet  --ESP-NOW field + membership-->
    any plugged-in C3  --C3JSON-->  scripts/c3-bridge.py  -->  /tmp/metafield/csi.jsonl
```

`run-arch.sh` starts the C3 bridge next to the CYD CSI bridge. Both write the same jsonl. `hello_view` already upserts a sensor entity per `body_id` (`c3-01` … `cyd-…`).

Need `pyserial`. Flash `c3-field-swarm` `main` after the C3JSON commit so neighbor fields ride in one snapshot. Older firmware still prints `[C3]` human lines; without `C3JSON` the bridge waits until that firmware is on the boards.
